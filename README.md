# Pythia — универсальный шашечный движок

**Pythia** — это универсальный шашечный движок на Python, задуманный с расчётом на поддержку множества вариантов игры в шашки. Архитектура построена так, чтобы правила конкретных вариантов игры были подключаемыми модулями, а не жёстко зашитой логикой.

## Цели проекта

На первом этапе планируется реализовать возможность игры по правилам:

- **Русские шашки** (8×8);
- **Международные шашки** (10×10);
- **Бразильские шашки** (8×8).

В дальнейшем набор вариантов можно расширять (английские шашки, пул, чекерс и другие), не переписывая ядро движка.

## Возможности

- Гибкое представление доски с поддержкой разных размеров: 8×8, 10×10, 12×12;
- Разделение базовых сущностей (игрок, фигура, ранг, состояние клетки) и представления доски;
- Расширяемая система «строителей» доски (`square_builders`) для инициализации полей под конкретный вариант игры.

## Структура проекта

```
src/pythia/
├── core/           # Базовые сущности игры
│   ├── player.py       # Игрок (белые/чёрные)
│   ├── piece.py        # Фигура на доске
│   ├── rank.py         # Ранг фигуры (простая / дамка)
│   └── square_state.py # Состояние клетки доски
├── damboard/       # Представление игровой доски
│   ├── damboard.py           # Класс доски Damboard
│   ├── board_size.py         # Размеры доски
│   └── square_builders/      # Строители начальной расстановки
│       └── standard_builder.py
└── movegen/        # Генерация ходов (в разработке)
```

## Требования

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) — менеджер пакетов и окружений

## Установка и запуск

Клонируйте репозиторий и установите зависимости:

```bash
uv sync
```

## Разработка

### Запуск тестов

Тесты написаны с использованием [pytest](https://pytest.org):

```bash
uv run pytest
```

### Линтинг

Проект использует [ruff](https://docs.astral.sh/ruff/) в качестве линтера и форматтера:

```bash
uv run ruff check
uv run ruff format
```
