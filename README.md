# Pythia

Библиотека на Python для работы с шашечными позициями: представление доски,
разбор и генерация FEN (PDN), генерация ходов и применение/отмена ходов.

Проект находится в ранней стадии развития (версия `0.1.0`): уже реализованы
доска, формат позиции и генераторы ходов для русских и международных шашек,
ведётся работа над движком и поиском.

## Возможности

- **Доска** — плоский массив клеток с рамкой, отображение между номерами
  игровых полей (`1..N`) и внутренними индексами, учёт фигур каждого цвета.
- **FEN (PDN)** — разбор строки позиции и обратная сборка строки из доски.
- **Генерация ходов** — тихие ходы и цепочки взятий для простых шашек и дамок,
  с учётом обязательности и максимальности взятия.
- **Применение ходов** — `do_move` / `undo_move` с корректным восстановлением
  позиции и очереди хода.
- **Варианты игры** — русские и международные шашки (бразильские шашки
  используют правила взятия международных шашек на доске 8×8).
- **Тесты** — `pytest`-набор по всем генераторам ходов, доске и FEN.

## Поддерживаемые варианты

| Вариант | Размер доски | Правила взятия |
| --- | --- | --- |
| Русские шашки | 8×8 | Обязательное взятие, допустим любой вариант боя |
| Бразильские шашки | 8×8 | Как в международных шашках: обязательное взятие, только максимальный бой |
| Международные (100 клеток) | 10×10 | Обязательное взятие, только максимальный бой |

## Установка

Требуется Python 3.12+ и [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

Рантайм-зависимостей нет; для разработки используются `pytest` и `ruff`.

## Быстрый старт

```python
from pythia.core.player import Player
from pythia.damboard.damboard import DamBoard
from pythia.movegen.russian_move_gen import RussianMoveGen
from pythia.search.move_func import do_move, undo_move

# Пустая доска 8×8 с расстановкой из FEN (PDN)
board = DamBoard()
board.setup("W:W9,10,11,12:B21,22,23,24")

generator = RussianMoveGen(board, Player.WHITE)
moves = generator.generate_move_list()

move = moves[0]
do_move(board, move)
print(board.to_fen())   # позиция после хода
undo_move(board, move)  # возврат к исходной позиции
```

Строку позиции можно получить и из самой доски:

```python
board.setup("W:W9,K10:B21,K22")
print(board.to_fen())  # W:W9,K10:B21,K22
```

## Представление доски

Доска хранится плоским массивом длиной `(height + 2) * (width + 2)`: по
периметру добавлена рамка толщиной в одну клетку, заполненная состоянием
`OUT_OF_BOARD`. Рамка позволяет генераторам ходов двигаться по диагоналям без
отдельных проверок границ — любая клетка за пределами доски уже помечена как
непроходимая.

Игровые (тёмные) поля нумеруются слева направо и сверху вниз, начиная с `1`.
Класс [`DamBoard`](src/pythia/damboard/damboard.py) предоставляет два
отображения:

- `ndx_of_number(number)` — номер поля `1..N` → внутренний индекс массива;
- `number_at(ndx)` — внутренний индекс → номер поля `1..N`.

Состояния клетки (`SquareState`): `EMPTY`, `WHITE_MAN`, `WHITE_KING`,
`BLACK_MAN`, `BLACK_KING`, `TAKEN`, `OUT_OF_BOARD`. Состояние `TAKEN`
используется только в рабочих копиях доски во время перебора цепочек взятий:
взятая фигура остаётся на месте до конца хода, но не может быть взята повторно.

## Формат FEN (PDN)

Позиция записывается строкой:

```text
<цвет хода>:W<белые поля>:B<чёрные поля>
```

- `<цвет хода>` — `W` или `B`;
- поля перечисляются через запятую;
- дамка помечается префиксом `K` (регистр не важен);
- завершающая точка в секции игнорируется, пустая секция допустима.

Примеры:

```text
W:W9,10,11,12:B21,22,23,24
B:W9,K10:B21,K22
```

Разбор выполняет [`Fen`](src/pythia/pdn/fen.py:42), сборку —
[`fen_from_states()`](src/pythia/pdn/fen.py:8) (используется в
[`DamBoard.to_fen()`](src/pythia/damboard/damboard.py:145)).

## Генерация ходов

Каждый генератор реализует протокол
[`BaseMoveGenerator`](src/pythia/movegen/base.py:7) с единственным методом
`generate_moves(board, square_ndx) -> list[Move]`. Ход
[`Move`](src/pythia/core/move.py:7) содержит исходную и конечную клетки,
состояния фигуры до и после хода, а также список взятых фигур в порядке взятия.

### Простые шашки

- [`WhiteManMove`](src/pythia/movegen/standard/white_man_move.py:6) — тихие ходы
  белой шашки только вперёд (в сторону уменьшения индекса).
- [`BlackManMove`](src/pythia/movegen/standard/black_man_move.py) — тихие ходы
  чёрной шашки только вперёд (в сторону увеличения индекса).
- [`KingMove`](src/pythia/movegen/standard/king_move.py:6) — тихие ходы дамки на
  любое расстояние по четырём диагоналям.
- [`RussianManCapture`](src/pythia/movegen/standard/russian_man_capture.py:8) —
  бой простой шашки по русским правилам: удар вперёд и назад на одну клетку,
  продолжение боя обязательно.
- [`InternationalManCapture`](src/pythia/movegen/standard/international_man_capture.py:7)
  — бой простой шашки по международным правилам: превращение фиксируется
  только по последней клетке хода.
- [`KingCapture`](src/pythia/movegen/standard/king_capture.py:7) — бой дамки:
  перепрыгивание фигуры противника с приземлением на любое свободное поле за
  ней и продолжением цепочки, пока это возможно.

### Русские шашки

[`RussianMoveGen`](src/pythia/movegen/russian_move_gen.py:13):

1. собирает все доступные цепочки взятий;
2. если взятия есть — возвращает их (взятие обязательно);
3. иначе возвращает тихие ходы.

Ключевая особенность: допустим **любой** вариант боя, а не только снимающий
максимальное число фигур. Кроме того, простая шашка, попавшая на дамочный ряд
в процессе боя, немедленно превращается в дамку и продолжает взятие по
правилам дамки (за это отвечает `KingCapture.continue_capture`).

### Международные шашки

[`InternationalMoveGen`](src/pythia/movegen/international_move_gen.py:13):

1. собирает все цепочки взятий;
2. оставляет только ходы с максимальным числом снятых фигур;
3. если взятий нет — возвращает тихие ходы.

Простая шашка в международных шашках продолжает бой как простая и превращается
в дамку только в конце хода, если конечная клетка находится на дамочном ряду.

Бразильские шашки используют те же правила взятия, что и международные
(обязательное взятие, только максимальный бой, превращение простой шашки
фиксируется лишь по последней клетке хода), но играются на доске 8×8.

### Применение и отмена ходов

[`do_move()`](src/pythia/search/move_func.py:26) снимает фигуру с исходной
клетки, удаляет взятые фигуры, ставит фигуру на клетку назначения в состоянии
`move.after_state` (уже учитывающем превращение) и передаёт очередь хода
сопернику. [`undo_move()`](src/pythia/search/move_func.py:51) восстанавливает
позицию и очередь хода в обратном порядке.

## Тесты

```bash
uv run pytest
```

Набор покрывает доску, FEN, тихие ходы и взятия для простых шашек и дамок, а
также генераторы русских и международных шашек.

Линтер:

```bash
uv run ruff check
```

## Известные ограничения и планы

- `core/game_type.py` ссылается на модуль `movegen/rules.py`, которого пока нет;
  в `engine/game_type.py` есть дублирующее перечисление. Планируется свести
  описание вариантов игры в одно место.
- Конструктор `DamBoard` создаёт доску с пустыми игровыми полями; начальная
  расстановка задаётся через `setup()` (FEN/PDN).
- Движок и поиск (оценка позиции, перебор, выбор хода) находятся в разработке.
- В планах — расширение набора вариантов (чекерс, пул), генерация нотации PDN
  и бенчмарки генератора ходов.
