# Модуль `pythia.pdn.parser` — чтение партий из PDN

## Постановка

PDN (Portable Draughts Notation) — текстовый формат записи партий в шашки.
Парсер читает файлы PDN и по каждой партии строит объект, содержащий:

- значения полей из заголовка партии (Event, White, Black, Result и т.д.);
- список позиций, которые возникали после каждого хода в партии.

Первый поддерживаемый вариант — международные шашки (доска 10x10, партии
в цифровой нотации FMJD). Эталонный файл для проверки —
`parser_pdn_international.pdn` в корне проекта: одна партия, 124 полухода,
финальная позиция — две чёрные дамки на полях 23 и 47, белых фигур нет.

## Структура PDN

Файл состоит из партий. Каждая партия — блок заголовка (пары
`[Key "Value"]`, по одной на строке) и текст ходов (movetext):

```
[Event "Rated Bullet game"]
[White "fred"]
[Result "0-2"]

1. 34-29 18-22 2. 40-34 12-18 ... 0-2
```

В movetext встречаются:

- номера ходов (`1.`, `12...`);
- полуходы: тихие через `-` (`34-29`), взятия через `x` или `:`
  (`28x19`, `40x7`). Нотация взятия может опускать промежуточные поля
  приземления (`39x19` вместо `39x28x19`);
- результат партии отдельным токеном (`1-0`, `0-1`, `1-1`, `0-2`, `2-0`,
  `1/2-1/2`, `*`);
- комментарии (`{...}` и `; ...` до конца строки) и варианты (`(...)`);
- заголовок `[FEN "..."]` — начальная позиция партии; при его отсутствии
  используется стартовая расстановка международных шашек
  (`STANDARD_START_FEN`: белые 31–50, чёрные 1–20, первый ход у белых).

## Публичный интерфейс (`src/pythia/pdn/parser.py`)

### `PdnGame`

Партия, прочитанная из PDN:

- `headers: dict[str, str]` — тег заголовка -> значение;
- `positions: list[str]` — позиции в формате FEN/PDN. `positions[0]` —
  начальная расстановка, `positions[i]` — позиция после i-го полухода;
  цвет хода в каждой позиции — сторона, делающая следующий ход.

### `PdnParser(rules=INTERNATIONAL, board_size=BoardSize.BIG)`

- `parse(text: str) -> list[PdnGame]` — читает все партии из PDN-текста;
- `parse_file(path: str) -> list[PdnGame]` — читает файл.

Параметры конструктора задают правила варианта игры (влияют на легальность
ходов при replay) и размер доски. Новая партия начинается, когда после
movetext встречается строка заголовка; партия без movetext получает в
`positions` единственную начальную позицию.

## Как работает разбор

1. **Разбор movetext** (`_move_notations`): из текста отбрасываются
   комментарии, варианты, номера ходов и токены результатов; каждый
   оставшийся токен разбирается в пару *(номера полей пути, признак
   взятия)*. Нераспознанный токен — `ValueError`.
2. **Replay партии** (`_replay`): на доске `Damboard` (параметры —
   из `[FEN]` или стартовая расстановка) создаётся `MoveGenerator` с
   заданными правилами. Каждый ход из нотации сопоставляется с легальным
   ходом, сгенерированным по правилам (`_match_move`), и применяется
   `make_move`. Так легальность ходов, побитые фигуры и превращения в
   дамку вычисляются движком, а не из нотации.
3. **Сопоставление хода** (`_match_move`): сначала фильтр по типу хода
   (взятие/тихий — по разделителю нотации), затем ищется точное
   совпадение пути; если нотация опускает промежуточные поля взятия —
   совпадение по крайним полям (начало и конец). Ход должен определяться
   однозначно, иначе — `ValueError`.
4. **Фиксация позиции**: после каждого полухода позиция рабочего
   состояния генератора (`generator.states`) переводится в FEN/PDN общей
   функцией `pythia.pdn.fen.fen_from_states()` (та же, что используется
   в `Damboard.to_fen`).

## Связанные изменения

- `src/pythia/pdn/fen.py`: из `Damboard.to_fen` вынесена общая функция
  `fen_from_states(states, number_of, start_color)` — сборка FEN из
  отображения «внутренний индекс -> состояние клетки»; `Damboard.to_fen`
  делегирует ей (поведение не изменилось).
- `Fen.parse` теперь не падает на пустых секциях (например, финальная
  позиция без белых фигур `W:W:BK23,K47`).
- `pythia/pdn/__init__.py` экспортирует `Fen` и `fen_from_states`;
  парсер импортируется напрямую как `pythia.pdn.parser` — это позволяет
  не создавать циклический импорт (`damboard` импортирует `pdn.fen`).

## Тесты

`tests/test_pdn/test_parser.py` — на эталонном файле
`parser_pdn_international.pdn`:

- партия читается, все поля заголовка на месте;
- 124 полухода -> 125 позиций, первая — стартовая расстановка;
- финальная позиция: белых фигур нет, две чёрные дамки на полях 23 и 47
  (проверено через `Damboard.setup` + ранги через `Fen`);
- синтетические сценарии: взятие с токеном `*`, две партии в одном
  тексте, нераспознанный токен и нелегальный ход дают `ValueError`.
